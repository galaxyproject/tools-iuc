# Test Data for SameStr Data Manager

## MetaPhlAn Test Database

The file 'mpa_test-db-without-one-marker.pkl' was generated from 'mpa_test-db-without-one-marker.json' using the 'customizemetadata.py' script.

Both original files can be found in the MetaPhlAn tool repository:
https://github.com/galaxyproject/tools-iuc/tree/main/tools/metaphlan

### Regenerating the PKL file

If needed, the PKL file can be generated by using the following command:

```bash
python customizemetadata.py transform_json_to_pkl \
    --json mpa_test-db-without-one-marker.json \
    --pkl mpa_test-db-without-one-marker.pkl
```

### Bowtie2 index

The data manager reconstructs the MetaPhlAn marker FASTA from the bowtie2 index
with `bowtie2-inspect`, as real MetaPhlAn database directories do not keep the
marker FASTA. The `mpa_test-db-without-one-marker.*.bt2` index was built with
bowtie2 2.5.4 from `test-db-without-one-marker.fasta` in the MetaPhlAn tool
repository (a small `--ftabchars` keeps the index files small):

```bash
bowtie2-build --ftabchars 4 \
    ../../../tools/metaphlan/test-data/test-db-without-one-marker.fasta \
    mpa_test-db-without-one-marker
```

`mpa_test-db-without-one-marker_VSG.fna` is intentionally empty. It mimics the
empty `<dbkey>_VSG.fna` shipped with the MetaPhlAn TOY database, which an earlier
version of this data manager mistook for the marker FASTA.
