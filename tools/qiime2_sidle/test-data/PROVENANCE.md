The db_alignedsequences.qza fixture contains only the 18 reference IDs present in reconstruction_map.qza, selected from the original aligned reference and reimported with QIIME 2 2021.4.0. It retains the complete alignment for those IDs. This reduces the fixture from 5.4 MB to 14 KB without altering the reconstructed fragment. Other QZA fixtures retain their original embedded execution provenance.

Runtime: quay.io/nf-core/pipesidle:0.1.0-beta (QIIME 2 2021.4.0, SIDLE plugin 2020.08, q2galaxy 2021.4.0). Native wrappers were generated by q2galaxy template plugin sidle and adapted to current Galaxy XML validation. QIIME artifact archive version 5 is required; version 6 artifacts cannot be read by this pinned runtime.

QIIME artifact provenance/UUID serialization is deliberately excluded from scientific comparison. All data members are compared: sequence identities, BIOM feature/sample counts and complete TSV rows. The source passes null for all region labels during reconstruction; these test cases preserve that source behavior explicitly.
